Demo 7 — Professional Services (Consultation-First)
“Modern Consultant”
Project Goal

Create a high-trust professional services website demo suitable for:

Business consultants

Accountants

Advisory firms

Boutique legal or financial practices

Primary conversion: Book a consultation
Secondary conversion: Contact form + credibility reinforcement

This demo should feel:

Calm

Precise

Expensive

Strategically designed (not “templated”)

Think: top-tier consultancy / Swiss corporate design, not startup SaaS.

Target Audience

Business owners

SME directors

Founders

High-value professional clients

Users are:

Time-poor

Risk-averse

Comparing multiple providers

Sensitive to presentation quality

Style Direction (Non-Negotiable)
Overall Feel

Swiss / International Typographic Style

Strong grid discipline

Clear hierarchy

Intentional white space

No decorative flourishes

No “marketing hype” language

If it looks impressive without animation, it’s correct.

Color System

Base Palette (Neutral, Professional)

Role	Color
Background	Soft off-white #F8F9FA
Primary Text	Near-black #111111
Secondary Text	Muted grey #5F6368
Borders / Lines	Light grey #E5E7EB

Accent (Single Confident Color — choose ONE)
Use sparingly: CTAs, highlights, key links only.

Deep Blue: #1F3A5F (most universal)

Forest Green: #1E4D3B (advisory / accounting)

Charcoal Gold: #A8873A (legal / premium)

❌ No gradients
❌ No multiple accents
❌ No bright colors

Typography (Critical)
Headings

Inter Tight, Suisse Int’l, or Neue Haas Grotesk–style

Weight: 600–700

Tight line height

Large scale jumps

Example scale:

H1: clamp(3rem, 5vw, 4.5rem)

H2: clamp(2rem, 3vw, 3rem)

H3: 1.4–1.6rem

Body

Inter / Source Sans 3

Size: 16–18px

Line height: 1.6–1.7

Calm, readable, professional

Typography Rules

No all-caps paragraphs

No letter-spacing gimmicks

No script or serif fonts

Headings do the work, not effects

Layout System
Grid

Max width: 1200–1280px

12-column grid

Consistent vertical rhythm

Clear section separation using space, not color blocks

Spacing

Sections breathe

Avoid stacking too many elements vertically

Prefer fewer, stronger sections
